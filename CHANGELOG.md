# JMGO Temp — история версий

Нумерация общая для APK (JMGO-Temp-x.y.apk) и браузерной версии (jmgo_dash.py).

## 1.3
- Новое имя пакета: `com.jmgo.jmgotemp` (было `io.github.jmgotemp`). Прошивка JMGO (hippo) не закрывает приложения с именем `com.jmgo.*`: при нехватке памяти (проверено на N5 Pro) и, по коду прошивки, при уходе в сон. Поэтому окно поверх фильма больше не пропадает, и пункт «Не выгружать приложения» в клоне настроек для него не нужен. Для Android это новое приложение: старую версию нужно удалить, язык и угол окна выставить заново.
- Вентиляторы: убрано сообщение прошивки «ERROR:true / fanStatus = 0», оно залипало после одиночного сбоя датчика. Вместо него своё предупреждение: «Вентилятор N: 0 об/мин при мощности P % — похоже, не крутится». Оно появляется, только если вентилятор стоит 3 опроса подряд при мощности выше 30 % (если мощность неизвестна — когда второй вентилятор крутится быстрее 300 об/мин), и снимается само, когда обороты вернутся.
- Диафрагма (N5S Ultra Max): в плитке яркости — «диафрагма F3» (в режимах «Макс.» — «Макс. · диафрагма F2»), в окне поверх фильма — «F3» после яркости, окно остаётся в 3 строки. На моделях без диафрагмы (N5 Pro) ничего не добавляется. APK берёт значение из сервиса проектора, браузерная версия считает его по положению мотора диафрагмы.
- Подсказка с командой adb для разрешения окна показывает новое имя пакета.

## 1.2.1
- Яркость: исправлен сдвиг ступеней 1–5 (меню 1 показывалось как 0, 5 как 4). Ступени в проекторе хранятся как 0, 11, 22 … 100, а не 10, 20 … 100.
- AL 2.0: крупно — пункт меню (10/10), под ним «AL 2.0: сейчас ≈N/10 по току» — фактическая мощность лазеров по сцене, как было в 1.1. В окне поверх фильма: «Яркость 10/10 (AL ≈6)». Признак «AL включён» берётся из настройки, которую пишет сама прошивка.
- В «Производительности», Overlap и на белом экране по-прежнему «Макс.»: там ток фиксированный, ступень по нему не считается.
- Плитка процессора: два крупных числа — температура и загрузка («70° | 33%»), как у вентиляторов. Если система не даёт читать загрузку — только температура.
- Английский: сообщения об ошибках и подключении теперь переводятся (APK и браузер), название уведомления окна, консоль и `--help` браузерной версии — по языку системы.
- График: сбойный 0 об/мин заменяется прошлым значением — линия вентилятора без разрывов; 3 нуля подряд показываются как есть (вентилятор действительно стоит).
- График: близкие пороги лазеров (58 и 58,5 °C) подписаны одной меткой.

## 1.2
- Яркость берётся из настройки проектора (целое число /10), а не вычисляется по току красного лазера — раньше в режиме «Производительность» и на белом экране показывалась неверно.
- Фиксированные режимы яркости (Overlap, производительность, белый экран с повышенным током) показываются словами; ток R/G/B остаётся.
- Процессор: правильное название чипа (MediaTek MT9681 вместо внутреннего имени платформы), загрузка, частота и её максимум.
- Троттлинг: если система снижает потолок частоты — предупреждение, время начала, красная полоса на графике, отметка в «Максимум за сеанс» и в окне поверх фильма.
- На графике процессора добавлена загрузка (%).
- Карточка «Частота процессора»: если прошивка закрепила частоту (у N5 Pro — 1800 МГц), так и пишется; при троттлинге — «⚠ троттлинг, потолок N МГц».
- Окно поверх фильма: при троттлинге — «⚠ троттлинг N МГц» (загрузка процессора — только на дашборде, чтобы не отвлекать).
- Обновление: APK — раз в 1 с, браузер — раз в 2 с (температуры DMD/лазеров сам проектор обновляет раз в 2–10 с).
- Одиночные провалы оборотов вентилятора до 0 (сбой датчика) отбрасываются.
- Английский язык: переключатель RU/EN, выбор запоминается; по умолчанию — язык системы.

## 1.1
- N5S Ultra Max (KD11CN): пороги берутся из его прошивки — лазеры: снижение яркости 58 °C, отключение 58,5 °C; вентиляторы держат лазеры ~48 °C (в ярких режимах 52).
- DMD: если прошивка читает температуру из самой матрицы через DLP (на N5S UM — при прошивке DLP 6.0.0+), показывается её порог отключения (71 °C) и подпись «датчик в самой матрице».
- Строка конфига с фиксированными оборотами больше не показывается как «цель вентиляторов».
- Комментарии в конфиге прошивки больше не путаются с настоящими значениями.
- Версия видна в карточке «Версии» (в APK — «JMGO Temp», в браузере — «Дашборд»); у скрипта есть `--version`.

## 1.0
